## About This Repository

`my-learning-process` 是我的个人学习仓库，主要用于记录本科阶段在课程学习、自主练习和数据科学项目中写过的代码。

作为一名上海财经大学统计学方向的学生，我希望通过这个仓库系统整理自己在以下领域的学习过程：

- C 语言程序设计
- 基础算法与数据结构
- Python 数据分析
- 统计建模与机器学习
- Kaggle 入门项目实践
- 课程作业与个人练习代码

这个仓库不是一个完整的工程项目，而是一份持续更新的学习档案。它记录的不只是代码结果，也包括我从基础语法到实际建模应用的成长路径。
