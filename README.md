## Overview

`my-learning-process` 是我的个人学习代码仓库，用来保存本科阶段上课、自学和项目练习中写过的代码。

这个仓库不是一个单一项目，而是一条持续积累的学习路线，内容包括：

- C 语言基础与算法练习
- Python 编程与数据处理
- 机器学习入门项目
- Kaggle 数据竞赛练习
- 课程作业与阶段性实践代码

我希望通过这个仓库记录自己从基础语法、算法思维到机器学习应用的成长过程。
